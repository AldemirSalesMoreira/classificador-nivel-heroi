# 🦸 Classificador de Nível de Herói

Projeto desenvolvido como desafio da DIO para praticar:
- Variáveis
- Estruturas de decisão
- Operadores lógicos

## 🧠 Funcionamento
O sistema classifica o nível do herói com base na quantidade de XP.

## 🚀 Tecnologias
- JavaScript (ou Python)
